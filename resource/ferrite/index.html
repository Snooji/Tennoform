Ferrite

Resource

Found on: Mercury, Earth, Lua, Neptune, and the Void.

Best place to farm it: Apollodorus, Mercury (Survival).

Any Mercury/Earth/Lua/Neptune node. Run Nekros (Desecrate) + Smeeta Kavat for x2-x4.

Early game

  • Coba, Earth (Defense, level 6–16): Dark Sector +15% resources. Endless waves; stand still and loot
  • Tikal, Earth (Excavation, level 6–16): Dark Sector +15% resources. Endless; excavators also drop resource caches
  • Lith, Earth (Defense, level 1–6): Endless waves; stand still and loot

Mid game

  • Kelashin, Neptune (Survival, level 30–40): Dark Sector +30% resources. Endless; resource drops pile up over time
  • Ani, Void (Survival, level 20–25): Endless; resource drops pile up over time
  • Yuvarium, Lua (Survival, level 25–30): Endless; resource drops pile up over time

Late game

  • Mot, Void (Survival, level 40–45): Endless; resource drops pile up over time
  • Circulus, Lua (Survival, level 80–100): Endless; resource drops pile up over time
  • Apollo, Lua (Disruption, level 35–40): Endless with high drop rate

Drop chances

  • Neptune/Cephalon Capture (Conclave) · Rot B: 12.7%
  • Saturn/Annihilation (Conclave) · Rot B: 12.7%
