Argon Crystal

Resource

Found on: Missions in the Void.

Best place to farm it: Mot, Void (Survival).

Only from the Void. Decays 50% daily. Farm right before crafting.

Early game

  • Taranis, Void (Defense, level 10–15): Endless waves; stand still and loot
  • Hepit, Void (Capture, level 10–15): Very fast run, good for crates
  • Teshub, Void (Exterminate, level 10–15): Fast, lots of kills

Mid game

  • Ani, Void (Survival, level 20–25): Endless; resource drops pile up over time
  • Belenus, Void (Defense, level 30–35): Endless waves; stand still and loot
  • Tiwaz, Void (Mobile Defense, level 20–25): Quick objective

Late game

  • Mot, Void (Survival, level 40–45): Endless; resource drops pile up over time
  • Mithra, Void (Interception, level 40–45): Endless; good with loot frames
  • Aten, Void (Mobile Defense, level 40–45): Quick objective

Drop chances

  • Corrupted Vor: 50%
  • Deimos/Formido (Caches) · Rot C: 19.4%
